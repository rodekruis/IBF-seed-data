# Pipeline Mock Data

Synthetically generated data that simulates external data sources. Used by MOCK_ALERT and MOCK_NO_ALERT pipeline run targets for integration testing and local development.

This data is NOT real forecast data.

## Structure

```
mock-data/
├── floods/
│   └── glofas-discharge/       Mock GloFAS discharge NetCDF files
└── drought/
    └── mock_ecmwf_seas5_*.grib Mock ECMWF SEAS5 seasonal precipitation forecasts
```

## floods/glofas-discharge/

Mock GloFAS discharge NetCDF files that simulate the data normally fetched from the GloFAS FTP server.

- `{ISO3}_glofas_discharge_alert.nc` — Produces exactly 1 alert at the lowest-threshold station (exceeds RP5 on all lead times)
- `{ISO3}_glofas_discharge_no-alert.nc` — All stations below threshold (no alerts)

Properties:
- Format: NetCDF4, float32
- Resolution: 0.05° (~5km)
- Dimensions: 8 lead times × lat × lon (country-clipped with buffer)
- Variable: `dis` (discharge in m³/s)

Countries: ETH, KEN, MWI, PHL, SSD, UGA, ZMB

Generated by: [`generate_mock_glofas_discharge.py`](https://github.com/rodekruis/IBF/blob/main/data/data_management/seed_data_management/generate_mock_glofas_discharge.py)

## drought/

Mock ECMWF SEAS5 seasonal forecast data (total precipitation).

- `mock_ecmwf_seas5_forecast_monthly_tp.grib` — Mock forecast
- `mock_ecmwf_seas5_hindcast_monthly_tp.grib` — Mock hindcast

These simulate the ECMWF Copernicus Climate Data Store downloads used by the drought pipeline.
