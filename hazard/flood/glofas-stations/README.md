# GloFAS Station Thresholds

The `*_station_thresholds.json` files contain one record per GloFAS station. The `pcodes` field contains the admin-area place codes used for that country's flood alert configuration and runtime exposure calculation.

## Updating Station Mappings

Mappings are generated by the flood-specific `update_glofas_station_area_mapping`
script in the IBF repository:

```bash
cd /path/to/IBF/data
uv run python -m data_management.seed_data_management.flood.update_glofas_station_area_mapping
```

The default command processes the configured flood countries: ETH, KEN, MWI,
PHL, SSD, UGA, and ZMB. ZWE and LSO are intentionally excluded because they
do not currently have flood station-threshold data. To process one country:

```bash
uv run python -m data_management.seed_data_management.flood.update_glofas_station_area_mapping --country ZMB
```

The script uses the river GeoPackage at:

```text
https://510ibfsystem.blob.core.windows.net/ibfdatapipelines/river-flood/rivers/rivers.gpkg
```

It downloads the file to the ignored local path `data/data/input/rivers.gpkg`
when no local file is supplied. This follows the repository's
`DATA_CACHE_DIR=./data/` convention. An existing local file can be provided
with `--river-file /path/to/rivers.gpkg`.

The script uses the flood pipeline's configured levels: adm2-3 for ETH, KEN,
MWI, PHL, SSD, and ZMB, and adm2-4 for UGA. It stores only the deepest
configured level in each output file. That is the level consumed by flood alert
configuration and the runtime pipeline. The river-derived fallback follows the
original pipeline logic: buffered river geometries are dissolved into connected
components, and the nearest component is assigned to each station. The deepest
configured admin level is then mapped by direct river intersection rather than
by including every child of a matched parent. After candidate mappings are
calculated, each deepest-level admin area is assigned to only one station, using
the nearest station point as the deterministic tie-breaker. Threshold values
are preserved.
